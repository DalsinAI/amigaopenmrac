# OpenMRac for GFOS

The AmiCradle Team's port of OpenMRac (Franticware's split-screen 3D car
racing game, the open release of MultiRacer) to GFOS: AmigaOS 3.2 with
GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2 and OpenGL (GFOpenGPU). It
ships as a release archive with an Installer and as the GFOpenUp part
Parts/OpenMRac.

Upstream and its data are fetched at build time (package/openmrac.lock);
this repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
